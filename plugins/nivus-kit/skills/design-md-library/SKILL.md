# DESIGN.md Library

Source: https://github.com/VoltAgent/awesome-design-md (MIT). Each file in `brands/<name>/DESIGN.md` describes colors, typography, spacing, components and layout rules of an inspired interpretation of that brand's design language.

## How to use

1. Identify the brand the user referenced (or suggest 2–3 fitting ones if they only describe a vibe, e.g. "dark tech dashboard" → vercel, linear.app, raycast).
2. Read `brands/<name>/DESIGN.md` and follow its tokens and rules when building the UI.
3. If the user wants it as the project's permanent design system, copy it to `DESIGN.md` at the repository root.
4. Combine with the `taste-skill` guidance and the Web Interface Guidelines review. Never copy logos or trademarked assets — use the design language only.
